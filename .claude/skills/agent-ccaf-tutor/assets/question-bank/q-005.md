## Question

Your agent needs to insert a new helper function into the middle of a 150-line utility module, between two existing functions. The Edit tool fails because its `old_string` parameter cannot find unique text to match — the file has repetitive docstrings, variable names, and structural patterns.
What's the most reliable way to complete this insertion?

## Options

- **A)** Use Edit's `replace_all` parameter to target a common pattern and embed the new function in the replacement text
  - **Rationale:** `replace_all` would mutate every occurrence of the pattern — corrupting the whole file.
- **B)** Use Edit with an extremely long `old_string` capturing 30+ lines of context to guarantee uniqueness
  - **Rationale:** Long, brittle match strings frequently miss due to whitespace or minor edits and produce confusing failures.
- **C)** Use Bash to append the function definition to the end of the file using heredoc syntax
  - **Rationale:** Appending puts the function at the wrong location. The requirement is to insert between two existing functions.
- **D)** Use Read to load the file, add the function at the appropriate location, then Write the updated file
  - **Rationale:** Correct. When Edit's unique-match contract can't be satisfied in a repetitive file, fall back to Read → modify in memory at the intended line → Write the full file back.

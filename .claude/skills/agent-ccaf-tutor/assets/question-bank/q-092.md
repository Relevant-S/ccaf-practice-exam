## Question

A coordinator concatenates the outputs of 12 subagents into one long input for a synthesis step. Findings from the outputs placed in the middle are consistently missing from the final report, while the first and last outputs are well represented.

Which TWO changes best reduce this problem? (Choose 2.)

## Options

- **A)** Switch to a model with a larger context window.
  - **Rationale:** The input already fits. A bigger window does not change where the model's attention is weakest. The middle would still be under-used.
- **B)** Put a key-findings summary at the beginning of the aggregated input.
  - **Rationale:** Correct. Models process the beginning and end of long inputs most reliably and may skip findings in the middle. A summary at the start puts every key finding where attention is strongest.
- **C)** Add "read everything carefully and don't miss anything" to the synthesis prompt.
  - **Rationale:** A vague instruction does not change the position effect. The model already "tries" to read everything; the structure of the input is what needs to change.
- **D)** Organize the detailed results under explicit section headers.
  - **Rationale:** Correct. Clear section headers give the long input a structure the model can navigate, so middle sections are less likely to be skipped. Together with an up-front summary, this is the standard way to counter position effects.
- **E)** Randomize the order of subagent outputs on each run.
  - **Rationale:** This only changes which findings land in the middle. Some findings are still lost on every run — just different ones each time.

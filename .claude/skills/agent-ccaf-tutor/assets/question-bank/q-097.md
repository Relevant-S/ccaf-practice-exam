## Question

A support agent spent 30 turns on a warranty claim. It found that a firmware update bricked the customer's router (serial RX-4471-K), that the unit is 2 months inside warranty, and that a replacement needs regional-manager approval, which the agent does not have.

The manager who picks up the case will not see the conversation. What should the agent pass to `escalate_to_human`?

## Options

- **A)** The customer's messages plus the raw firmware log excerpts and the warranty-lookup output that prove the diagnosis.
  - **Rationale:** This is raw evidence with no conclusion. The manager would have to redo the 30 turns to reach the diagnosis the agent already made.
- **B)** The full conversation transcript with all tool results attached.
  - **Rationale:** Complete, but far too long to read in the time a manager has. The point is buried, and the manager still has to work out what to do.
- **C)** A structured summary: customer ID and serial number, root cause (firmware update bricked the unit), warranty status, and recommended action (approve a replacement).
  - **Rationale:** Correct. A structured handoff gives the identifiers, the cause, the status and the recommended action. The manager can act straight away without seeing the conversation.
- **D)** The root cause and the recommended action.
  - **Rationale:** The customer and device identifiers and the warranty status are missing. The manager cannot act on the case without knowing whose unit it is and whether it is covered.

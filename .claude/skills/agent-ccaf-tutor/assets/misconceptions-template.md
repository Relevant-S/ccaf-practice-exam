# Misconceptions

_Pattern library of {user_name}'s recurring wrong-reasoning patterns. Each entry is a pattern, not a single mistake. Track the underlying misconception, the Task Statement(s) it appears in, the questions that surfaced it, and a count + recency._

_A misconception is resolved only when it has been confirmed **cold** (after a real gap, not right after tutoring), with the **right reasoning** on the **first answer**, including a **counter-case** where the drilled answer is wrong, and on at least one **bank** question. Until then, call it provisional. When resolved, mark it `resolved: true` with a date — but don't delete. The resolution date is useful context for the `progress` capability. Full rules: `references/memory-guidance.md`._

_One entry per pattern. When a pattern recurs, update its entry; never add a second one with the same name._

_When a misconception recurs (count reaches 2+), Richard's CREED standing order kicks in: surface it and propose targeted remediation at a natural break._

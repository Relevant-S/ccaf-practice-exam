# Practical Tasks

_Log of tutoring-mode practical tasks Richard has assigned to {user_name}, the user's submission summary, and Richard's feedback summary. Used by the `tutoring` capability to detect skill growth and avoid reassigning the same task verbatim, and by the `progress` capability as a depth indicator (a domain with completed practical tasks is more solid than one with just MCQ accuracy)._

_Entries are summaries, not full transcripts. If you want the full submission text, look in the session log for that date. This file is for at-a-glance reference._

_Old tasks (90+ days) where the topic is now Solid can be summarized into a one-line entry. Recent or struggling tasks stay full._

---

## Template for new entries

```markdown
### {Date} — {Task Statement code} — {Topic short name}

- **Task assigned:** {one-sentence description of what {user_name} was asked to do}
- **Type:** {design exercise | prompt critique | architecture trade-off | tool description rewrite | etc.}
- **Submission summary:** {what {user_name} actually produced — keep to 2-3 sentences}
- **Feedback summary:** {what was right / wrong / almost right — 2-3 sentences}
- **Mastery delta:** {topic moved from X to Y, or stayed at Y}
- **Follow-up:** {any open thread for next session}
```
